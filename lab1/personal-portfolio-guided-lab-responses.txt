Lesson 2: Create the Home Page
Question:
Is <div> a semantic element? Why or why not?

Student response:
Unlike other semantic tags like <header>, <nav>, and <footer>, the tag <div> does not tell other consumers of a web page what the content of the tag is.  Other consumers include assistive technologies, tools that reformat content for simplicity, and even search engines.

Lesson 6: Create the About page
Question:
Explain the difference between an ID selector and a class selector in CSS. When would you use each one?

Student response:
An ID selector will only target one element on the page, something unique.  A class selector will target several elements that will receive the same styling.
